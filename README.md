# 🌐 Project Overview

This project is an **interactive 3D virtual campus walkthrough** designed for the

**Institute of Management Research and Development (IMRD), Shirpur**

under the RCPET educational ecosystem.

Instead of simply viewing static photographs of the campus, users can enter a
browser-based 3D environment and explore the campus like a lightweight game.
